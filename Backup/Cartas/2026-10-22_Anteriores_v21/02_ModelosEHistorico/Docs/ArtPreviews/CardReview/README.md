# Fotos para revisão das cartas

Capturas reais da versão v15 na cena PlayerMovementTest, em 1200×720. As ofertas
usam o mesmo prefab e os mesmos controladores da partida, pelo modo DEV.

- `01-comuns.png`: ataque, rajada e blindagem comuns.
- `02-raras.png`: rajada, blindagem e propulsão raras.
- `03-epicas.png`: blindagem, propulsão e especial épicos.
- `04-lendarias.png`: ataque, rajada e blindagem lendários.
- `05-miticas.png`: rajada, blindagem e propulsão míticos.
- `06-versos.png`: novo verso militar, com recorte externo transparente.

As demais combinações também foram exibidas no ciclo completo de nove ofertas.
Validação local: 94 checks de Play Mode, 1464 checks de dados/controlador,
build Windows Unity 6000.6.4f1 e inicialização do player por dez segundos.
Ver `Docs/ModoDesenvolvedor.md` para repetir o fluxo.
