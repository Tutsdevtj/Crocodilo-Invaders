# Sons da abertura do lago v17

Dois efeitos procedurais originais, sem amostras de terceiros, criados por `create_audio.py` (Python padrão, seed fixa 1701). Mono PCM16/44100 Hz.

- `water-swell.wav`: 0,95 s de ruído filtrado e bolhas graves para preparar a entrada.
- `cururu-croak.wav`: 0,68 s de voz grave harmônica pulsada para o assentamento do Sapeneu.

Cópias idênticas em `Assets/Resources/LakeEntranceV17`. A apresentação usa os volumes locais 0,55/0,65 e roteia ao mixer Effects, com pausa pelo AudioListener. A arte visual é reaproveitada dos sprites do Sapeneu e das folhas v16; não há uma nova imagem de abertura gerada.

Sem commits ou publicação até o usuário finalizar.
